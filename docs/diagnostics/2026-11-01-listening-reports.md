# 网易云统计缺失与报表跨月诊断

## 实际证据

2026-11-01 14:24（Asia/Shanghai），在当前登录的开发版 Electron 主窗口内进行只读 GET 请求。未触发刷新按钮的播放 checkpoint、历史补报、清除待核或登出。

| 接口 | HTTP 状态 | 返回内容摘要 |
| --- | --- | --- |
| `/listen/data/today/song` | 200 | 161 条歌曲 |
| `/listen/data/realtime/report?type=month` | 200 | 起始日 2026-10-01，明细截至 2026-10-31，无 11 月 1 日明细 |
| `/listen/data/realtime/report?type=week` | 200 | 起始日 2026-10-25，明细截至 2026-10-31，无 11 月 1 日明细 |
| `/listen/data/total` | 200 | `totalDuration=24854641` 秒 |

重新请求并更换 timestamp 后仍然如此。已检查 `src/main/cache.ts`：没有为这些听歌报表实现应用缓存。API 模块只转发类型参数，没有在本地生成这些日期。另行读取历史报表接口，没有获得有效的当日时长；因此没有引入额外接口重试作为修复。

可以确定：时长缺失已在 API 返回数据中出现，早于 Vue 提取和显示。尚不能确定上游为什么未提供当前日期报表，也不能保证服务端何时更新。HTTP 200 不等于报表覆盖当前统计周期。

截图中“今日 · 歌曲数”下面的“累计收听”是今日时长；它不是最下面的账号总累计时长。歌曲数来自独立接口，不能据此推算今日时长。本次现场未复现总累计接口无值。

## 已证实的本地问题与修改

- `MusicInsightsStable.vue / refreshPendingRemoteDuration()` 在月报未更新到本月时提前返回，跳过独立周报。修复后继续请求周报，只采用匹配今天的显式日期明细。初次加载与轻量轮询采用相同的日期要求。
- 原提示把“HTTP 请求失败”“返回旧月份”“字段缺失”统一称为报表不可用。现在分别提示失败、报表未跨月更新和字段不完整；今日缺失时解释 `—` 的原因。没有有效远端时长时仍显示未知，不填入本机待核时长或零。
- 自然周兜底曾直接使用上游周累计，而上游实际周报从周日开始。现在合并月报与周报的显式日期，按周一至今天求和，重叠日期只计一次，同时处理跨月周。现场上游周累计 2079 分钟中包含前一个周日 84 分钟；按页面的自然周定义，应取已知日期的 1995 分钟。今日仍未知，这不是完整自然周的最终时长。
- `Number(null)`、空字符串和布尔值曾可能被读取为真实零时长。提取器现在保留未知状态，并拒绝失败响应中的数值。
- 原有五分钟限频的 ListenSync 日志增加报表状态、期望月份、最后有效明细日期、今日时长是否可用；仅接受有限状态和日期格式，不记录 Cookie、账号或完整响应。
- 换日/换账号时清除页面中的旧周期数值，不修改持久化账本、待核记录或听歌上传逻辑。

## 验证

- `npm run build:pre`：通过，包含 Vue TypeScript 检查和主进程/Renderer 构建。
- `npm run lint`：通过。
- 六个相关测试文件合计 79 项：78 通过，1 项既有失败。失败是趋势图测试要求源码包含 `{{ formatHours(tick) }}`，但当前 HEAD 的趋势组件已经没有该模板。该组件本次未修改，没有为通过无关断言修改图表。
- 新增两项隔离 Electron 集成测试：最终均通过。真实渲染统计页面、使用实际请求/提取/账本代码，替换账号 store、播放器动作和 HTTP 上游。覆盖旧月报、HTTP 503、空时长字段、周报先恢复、月报后恢复，以及跨月自然周去重。仅创建隔离测试 profile，无个人 Cookie；不进行真实听歌上传。
- 测试中的已接收 300 秒片段不会因报表缺失而被清空或重复记录；报表恢复后显示服务器值。
- 当前个人账本只读核对：诊断前后均为 1622 条、334992.0559205963 秒；按条目 ID 和 seconds 排序后的 SHA256 均为 `2e76540b97276b95ceafbf096b4d12cc808b67607c84230f208d610ff4b49501`。这是条目身份及原始时长检查，不代表全部报表确认元数据的字节级比较。

开发服务器曾因 esbuild 服务退出而出现空白，已重启恢复。恢复后在真实账号的 `/insights` 页面核对：月报提示最近明细为 2026-10-31；今日歌曲 161 首，今日时长 `—` 并显示缺失说明；账号总累计显示“287天 16小时”。主窗口应用内容存在且无 Vite 错误覆盖层，最后已关闭本机 Node 调试端口。

## 剩余验证

上游缺失的 11 月当日时长尚未恢复，不能声称该账号的 `—` 已变为真实数值。独立周报恢复与后续月报恢复使用受控响应实际验证；生产上游的自然恢复仍需等待并复查。Windows/macOS 共享这些无平台分支的统计代码，但本次 Electron 实测仅在 Linux 完成。

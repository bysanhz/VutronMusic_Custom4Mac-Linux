# VutronMusic v3.2.7 功能说明

## 桌面歌词样式预设

入口：`设置 → 歌词设置 → 桌面歌词样式预设`

- **应用**：将选中的预设应用到桌面歌词。
- **保存当前**：把当前字体、排版、颜色、翻译模式和封面控制区状态保存为自定义预设。
- **删除**：删除当前选中的自定义预设；内置预设不可删除。

预设不会修改桌面歌词窗口的位置、尺寸和锁定状态。

## 设置备份与恢复

入口：`设置 → 杂项设置 → 设置备份与恢复`

导出内容包括：

- 主题、语言和通用界面设置；
- 桌面歌词设置与自定义预设；
- 快捷键和播放偏好；
- 窗口缩放相关设置。

默认不会导出：

- 登录状态和认证凭据；
- 第三方 Cookie；
- 代理与真实 IP 设置；
- 本地音乐目录和缓存目录。

配置文件使用带 `schemaVersion` 的 JSON 格式。导入后应用会自动重新加载。

## 睡眠定时器

入口：`设置 → 音乐设置 → 播放器 → 睡眠定时器`

支持：

- 15、30、60、90 分钟后暂停；
- 当前歌曲结束后暂停；
- 实时查看剩余时间；
- 手动取消定时器。

到时会复用播放器已有的淡出和暂停逻辑。定时器只在当前运行周期内有效，退出应用后不会继续计时。
